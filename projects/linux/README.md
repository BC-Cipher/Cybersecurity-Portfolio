# Linux Infrastructure & Security

This section covers Linux systems administration, application hosting, storage, and security operations.

## Featured project

### [Linux Infrastructure, Service Deployment & Security Operations](linux-infrastructure-services-security/)

A multi-phase infrastructure project built from hands-on Ubuntu, AlmaLinux, and Linux Mint work. It brings together:

- QEMU/KVM virtualization, guest administration, and virtual networking
- Disk partition management, Samba file sharing, and Rsync synchronization
- Docker-based Nginx and Redis, plus Apache, MySQL, PHP, and HTTPS
- UFW and firewalld configuration, network and process monitoring
- Centralized TCP syslog collection between Linux systems
- Custom Bash and systemd disk reporting

The project focuses on what was configured, how it was tested, and what would need to change before using similar services in production.
