# Project Portfolio

This directory is reserved for larger, multi-week technical projects that combine multiple technologies, design decisions, implementation steps, validation, and documentation.

Focused exercises remain under [Technical Labs](../labs/).

## Project Standard

Each project added here should demonstrate more than a single tool or task and should include:

- Project goal and real-world context
- Architecture or environment
- Technologies used
- Implementation approach
- Security considerations
- Validation or testing evidence
- Key results and lessons learned
- Screenshots or diagrams when they add value

## Planned Project Domains

As larger coursework is documented, projects will be organized around areas such as:

- Windows Server, Active Directory & Identity
- Linux Systems & Automation
- Network Engineering & Segmentation
- Cloud Infrastructure & DevOps
- Backup, Recovery & Resilience
- Data Engineering & Database Design
- AI/ML for Security Analytics

Only completed, well-documented work will be added to the public project index.
