## Project Standard

Each project added here should demonstrate more than a single tool or task and should include:

- Project goal and real-world context
- Architecture or environment
- Technologies used
- Implementation approach
- Security considerations
- Validation or testing evidence
- Key results and lessons learned
- Screenshots or original diagrams when they add value
