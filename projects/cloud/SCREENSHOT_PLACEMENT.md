## Publishing Guidance
- Upload only PNGs, not the entire ZIP, source assignment documents, credential screens, or private keys.
- Inspect each image at full resolution before publishing for any remaining account identifiers, usernames, addresses, passwords, tokens, or access keys.
- Do not infer that a screenshot shows a successful test if it only shows configuration.
- Keep screenshots in their own `screenshots/` folder beside the relevant README. GitHub creates the folder automatically when the first file is uploaded to that path.
