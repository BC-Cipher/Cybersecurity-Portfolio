# Infrastructure Automation & Configuration Management

## [Cross-Platform Infrastructure Automation & Configuration Management](ansible-cross-platform-server-management/)

A connected portfolio case study covering AlmaLinux, Ubuntu, and Windows Server 2019 administration through Ansible. The work includes SSH access, Apache and IIS deployments, MySQL, Windows local identity and NTFS permissions, host firewall state, DHCP, Python/Bash account automation, and reusable Ansible roles.

The overview explains the system design, test evidence, troubleshooting, and security implications in accessible language. It also includes sanitized technical examples separate from the original executed work.
