# Network Routing and Infrastructure Security

Practical network engineering and security work in Cisco Packet Tracer, with configuration and verification screenshots from the original exercises.

These case studies cover multi-site network integration, dynamic routing and secure device administration, IPv6 routing and traffic restrictions, and encrypted connectivity between sites. Each overview separates observed results from settings that still need testing.

## Projects

### [Enterprise Network Integration, Segmentation & Security](enterprise-network-integration-segmentation-security/)

Designed and configured the primary site of a multi-location corporate Packet Tracer network. Documented IP addressing, VLANs, inter-VLAN routing, DHCP, TACACS+ authentication, ASA perimeter controls, and a security risk assessment. Separates recorded tests from proposed improvements.

**Focus:** Multi-site architecture, VLANs, DHCP, TACACS+, Cisco ASA, ACLs, security risk review.

### [Enterprise Network Routing and Secure Device Administration](enterprise-routing-secure-administration/)

Configured a multi-router network with OSPF, BGP route redistribution, TACACS+ and RADIUS services, SSH administration, and a Cisco ASA firewall in a later phase.

**Focus:** OSPF, BGP, VLANs, TACACS+, RADIUS, SSH, ASA, syslog.

### [IPv6 Routing, Firewall Policy and Layer 2 Security](ipv6-routing-and-access-controls/)

Configured OSPFv3 routing, inspected neighbor relationships, applied IPv6 access restrictions, and worked with ASA and switch port-security configurations.

**Focus:** IPv6, OSPFv3, ACLs, firewall routing, port security.

### [Site-to-Site IPsec VPN and Quality of Service](site-to-site-ipsec-vpn-qos/)

Configured a policy-based IPsec tunnel between two routed sites, inspected security association counters, and evaluated a QoS policy, including shortcomings visible in the output.

**Focus:** IPsec, IKEv1, crypto maps, QoS, troubleshooting.

## Scope

These are separate controlled training scenarios, not one production network. The screenshots show original device output. Passwords, shared keys, and classroom instructions are excluded.
