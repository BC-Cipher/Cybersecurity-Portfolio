# Technical Lab Index

Hands-on labs from cybersecurity coursework and technical practice, organized by the kind of work performed. Open a lab to see the tools, methods, results, and screenshots.

## Offensive Security & Penetration Testing

### [Windows System Exploitation & Privilege Escalation Lab](windows-system-exploitation-privilege-escalation/)
NTLMv2 credential auditing, Meterpreter reverse-shell validation, buffer-overflow analysis, and controlled Windows privilege escalation to SYSTEM.

### [Web Server & Application Penetration Testing Lab](web-server-application-security/)
Web reconnaissance, service enumeration, application attack-surface mapping, vulnerability assessment, credential testing, WordPress security analysis, and controlled remote code execution validation.

### [SQL Injection & Wireless Security Assessment Lab](sql-injection-wireless-security/)
SQL injection testing and OS command execution validation combined with IEEE 802.11 analysis and WPA2 credential-strength testing.

### [Network Attack, Detection & Evasion Lab](session-hijacking-analysis/)
Session hijacking, HTTP interception, ARP analysis, Snort IDS monitoring, Cowrie honeypots, and controlled Windows BITS file transfer.

### [Network Scanning, Enumeration & Evasion Lab](network-scanning-enumeration-evasion/)
Nmap service discovery, controlled decoy scanning, SNMP enumeration, automated network enumeration, and defensive analysis.

## Vulnerability Management & Threat Analysis

### [Vulnerability Research & Assessment Lab](vulnerability-research-assessment/)
MITRE CWE research, OpenVAS/Greenbone scanning, severity interpretation, Nikto web assessment, finding validation, and remediation analysis.

### [Malware Analysis & Network Threat Detection Lab](malware-analysis-network-threat-detection/)
Static malware analysis with Hybrid Analysis, Detect It Easy, and OllyDbg combined with Wireshark and Nmap analysis of ARP anomalies, sniffers, and insecure HTTP traffic.

### [DoS/DDoS Detection & Mitigation Lab](dos-ddos-detection-mitigation/)
Network-flow monitoring, resource-impact analysis, DDoS detection, and defensive source blocking in an isolated training environment.

## Cloud Infrastructure & Security

### [AWS IAM Access Control and Policy Validation](aws-iam-access-control/)

### [AWS VPC and EC2 Web Infrastructure](aws-vpc-ec2-infrastructure/)
Multi-AZ public and private subnet design, gateways, route tables and EC2 deployment.

### [Amazon S3 Object Storage and Versioning](aws-s3-object-storage-versioning/)
Bucket policies, access testing, object versions and recovery.

### [Amazon EBS Snapshots and Volume Recovery](aws-ebs-snapshot-recovery/)

### [AWS Lambda and EventBridge Automation](aws-lambda-eventbridge-automation/)

### [Amazon RDS MySQL Connectivity](aws-rds-mysql-connectivity/)
Private database networking, subnet groups, MySQL connectivity and troubleshooting.

### [AWS Elastic Beanstalk Monitoring](aws-elastic-beanstalk-monitoring/)
Managed web application deployment and infrastructure monitoring.

### [Cloud, Container and Cryptographic Security](cloud-container-cryptographic-security/)
Azure reconnaissance, Docker image vulnerability scanning and cryptographic operations.

See the [AWS cloud architecture project](../projects/cloud/aws-secure-scalable-web-architecture/).

### [AWS CloudFormation: Debugging & Version Control](aws-cloudformation-iac/)
Corrected S3 and EC2 YAML templates, validated imports, reviewed VPC and RDS definitions, and pushed Git revisions.

### [Azure ARM & Bicep Deployments](azure-arm-bicep-iac/)

### [Google Cloud Deployment Manager](google-cloud-deployment-manager/)
