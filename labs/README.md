# Technical Lab Index

This directory contains hands-on cybersecurity labs and technical exercises. The main portfolio page highlights the strongest projects, while this index provides access to supporting work that demonstrates additional breadth.

## Offensive Security

### [Windows System Exploitation & Privilege Escalation Lab](windows-system-exploitation-privilege-escalation/)
NTLMv2 credential auditing, Meterpreter reverse-shell validation, buffer-overflow analysis, and controlled Windows privilege escalation to SYSTEM.


### [Network Attack, Detection & Evasion Lab](session-hijacking-analysis/)
Session hijacking, HTTP interception, ARP analysis, Snort IDS monitoring, Cowrie honeypots, and controlled Windows BITS file transfer.

### [Web Server & Application Penetration Testing Lab](web-server-application-security/)
Web reconnaissance, service enumeration, application attack-surface mapping, vulnerability assessment, credential testing, WordPress security analysis, and controlled remote code execution validation.

### [SQL Injection & Wireless Security Assessment Lab](sql-injection-wireless-security/)
SQL injection testing and OS command execution validation combined with IEEE 802.11 analysis and WPA2 credential-strength testing.

### [Network Scanning, Enumeration & Evasion Lab](network-scanning-enumeration-evasion/)
Nmap service discovery, controlled decoy scanning, SNMP enumeration, automated network enumeration, and defensive analysis.

## Vulnerability Assessment

### [Vulnerability Research & Assessment Lab](vulnerability-research-assessment/)
MITRE CWE research, OpenVAS/Greenbone scanning, severity interpretation, Nikto web assessment, finding validation, and remediation analysis.

## Mobile, IoT & OT Security

### [Mobile, IoT & OT Security Assessment Lab](mobile-iot-ot-security/)
Android ADB exposure, controlled remote-access testing, mobile malware detection, MQTT packet analysis, and CAN replay testing.

## Cloud & Cryptography

### [Cloud, Container & Cryptographic Security Lab](cloud-container-cryptographic-security/)
Azure tenant reconnaissance, Docker image vulnerability scanning, layered hashing, HTTPS certificate deployment, AES disk encryption, and AI-assisted cryptographic operations.

## Reconnaissance & OSINT

### [OSINT & Network Reconnaissance Lab](osint-network-reconnaissance/)
Subdomain discovery, WHOIS analysis, DNS enumeration, network path mapping, automated Recon-ng host discovery, and HTML reporting.
